# Enterprise Legal Contract & Compliance Knowledge Graph (GraphRAG)

An enterprise-grade Java 21 & Spring AI service that parses multi-page commercial contracts, extracts legal entities/obligations, and constructs a Knowledge Graph in Neo4j to perform structured GraphRAG retrieval.

## Stack
- **Language**: Java 21 (Virtual Threads)
- **Framework**: Spring Boot 3.2+ / Spring AI
- **Database**: Neo4j Enterprise (Graph + Vector Search)
- **Document Ingestion**: Apache Tika
- **LLM Engine**: OpenAI gpt-4o / Spring AI Structuring
